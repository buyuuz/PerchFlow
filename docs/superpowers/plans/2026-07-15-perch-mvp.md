# Perch MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建 Perch MVP —— 单文件 Windows 进程与服务管理器,含进程监督、崩溃重启、cron 定时任务、资源监控、内置 Web UI 与完整 Windows 服务集成。

**Architecture:** 单个 tokio 运行时承载三部分:supervisor(进程监督 + 崩溃重启 + 退避)、scheduler(cron 定时任务)、axum HTTP server(JSON API + 内嵌前端 + SSE 日志)。唯一共享可变状态 `AppState` 用 `Arc` + 每进程 `RwLock`。配置存单个 TOML,API 可原子写回。前端为原生 HTML/JS,rust-embed 内嵌进二进制。

**Tech Stack:** Rust (stable),tokio,axum,serde/toml,rust-embed,windows-service,sysinfo,cron,thiserror,anyhow。

## Global Constraints

- 单个源文件不超过 400 行,超出必须按职责拆分。
- 单个函数不超过 50 行,超出必须拆解。
- 最小代码解决问题,不加未要求的功能、抽象、配置项。
- 二进制默认绑定 `127.0.0.1:9000`,所有 `/api/*` 需 `Authorization: Bearer <token>` 鉴权。
- 前端资源(Tailwind、字体)须本地化后内嵌,不依赖 CDN(Session 0 服务无外网)。
- 子进程崩溃是正常事件流,走重启逻辑,不作为 `Result::Err`。
- 库内部错误用 `thiserror`(`PerchError`),CLI 边界用 `anyhow`。
- 分两阶段:阶段一 = `perch run` 前台完整链路(可自动化测试);阶段二 = Windows 服务集成 + 交互菜单(需管理员权限,手动验证)。

```rust
use std::collections::VecDeque;

pub struct RingBuffer {
    capacity: usize,
    buf: VecDeque<String>,
}

impl RingBuffer {
    pub fn new(capacity: usize) -> Self {
        Self { capacity, buf: VecDeque::with_capacity(capacity) }
    }

    pub fn push(&mut self, line: String) {
        if self.buf.len() == self.capacity {
            self.buf.pop_front();
        }
        self.buf.push_back(line);
    }

    pub fn recent(&self, n: usize) -> Vec<String> {
        let start = self.buf.len().saturating_sub(n);
        self.buf.iter().skip(start).cloned().collect()
    }

    pub fn len(&self) -> usize {
        self.buf.len()
    }
}
```

```rust
use std::time::Duration;

pub struct Backoff {
    initial: u64,
    max: u64,
    attempt: u32,
}

impl Backoff {
    pub fn new(initial_secs: u64, max_secs: u64) -> Self {
        Self { initial: initial_secs.max(1), max: max_secs, attempt: 0 }
    }

    pub fn next_delay(&mut self) -> Duration {
        let secs = self.initial.saturating_mul(1u64 << self.attempt.min(20));
        self.attempt = self.attempt.saturating_add(1);
        Duration::from_secs(secs.min(self.max))
    }

    pub fn reset(&mut self) {
        self.attempt = 0;
    }

    pub fn attempts(&self) -> u32 {
        self.attempt
    }
}
```

```rust
pub mod model;
pub mod writer;

use crate::error::{PerchError, Result};
use model::Config;
use std::collections::HashSet;
use std::path::{Path, PathBuf};
use std::str::FromStr;

pub fn default_path() -> PathBuf {
    std::env::current_exe()
        .ok()
        .and_then(|p| p.parent().map(|d| d.join("perch.toml")))
        .unwrap_or_else(|| PathBuf::from("perch.toml"))
}

pub fn load(path: &Path) -> Result<Config> {
    let text = std::fs::read_to_string(path)
        .map_err(|e| PerchError::Config(format!("read {}: {e}", path.display())))?;
    let cfg: Config = toml::from_str(&text)
        .map_err(|e| PerchError::Config(format!("parse: {e}")))?;
    validate(&cfg)?;
    Ok(cfg)
}

pub fn validate(cfg: &Config) -> Result<()> {
    let mut seen = HashSet::new();
    for p in &cfg.process {
        if p.name.trim().is_empty() {
            return Err(PerchError::Config("process name empty".into()));
        }
        if !seen.insert(("p", p.name.as_str())) {
            return Err(PerchError::Config(format!("duplicate process name: {}", p.name)));
        }
    }
    for t in &cfg.task {
        if t.name.trim().is_empty() {
            return Err(PerchError::Config("task name empty".into()));
        }
        if !seen.insert(("t", t.name.as_str())) {
            return Err(PerchError::Config(format!("duplicate task name: {}", t.name)));
        }
        cron::Schedule::from_str(&t.schedule)
            .map_err(|e| PerchError::Config(format!("bad cron for {}: {e}", t.name)))?;
    }
    Ok(())
}
```

```rust
use crate::error::{PerchError, Result};
use std::io::Write;
use std::path::Path;

pub fn save(path: &Path, cfg: &Config) -> Result<()> {
    let text = toml::to_string_pretty(cfg)
        .map_err(|e| PerchError::Config(format!("serialize: {e}")))?;
    let dir = path.parent().unwrap_or_else(|| Path::new("."));
    let mut tmp = tempfile::NamedTempFile::new_in(dir)
        .map_err(|e| PerchError::Config(format!("tmp: {e}")))?;
    tmp.write_all(text.as_bytes())
        .map_err(|e| PerchError::Config(format!("write: {e}")))?;
    tmp.persist(path)
        .map_err(|e| PerchError::Config(format!("persist: {e}")))?;
    Ok(())
}
```

### Task 7: 单进程句柄与日志读取 process

**Files:**

**Interfaces:**
- Consumes: `config::model::ProcessDef`、`state::{ProcRuntime, ProcStatus}`

```rust
use crate::config::model::ProcessDef;
use crate::core::state::{ProcRuntime, ProcStatus};
use crate::error::{PerchError, Result};
use std::process::Stdio;
use std::sync::Arc;
use std::time::Instant;
use tokio::io::{AsyncBufReadExt, BufReader};
use tokio::process::{Child, Command};
use tokio::sync::RwLock;

pub fn build_command(def: &ProcessDef) -> Command {
    let mut cmd = Command::new(&def.cmd);
    cmd.args(&def.args);
    if let Some(cwd) = &def.cwd {
        cmd.current_dir(cwd);
    }
    for (k, v) in &def.env {
        cmd.env(k, v);
    }
    cmd.stdout(Stdio::piped()).stderr(Stdio::piped());
    cmd
}

pub async fn spawn_process(
    def: &ProcessDef,
    runtime: Arc<RwLock<ProcRuntime>>,
) -> Result<Child> {
    let mut cmd = build_command(def);
    let mut child = cmd.spawn().map_err(|e| PerchError::Process(format!("spawn {}: {e}", def.name)))?;

    let stdout = child.stdout.take();
    let stderr = child.stderr.take();
    let pid = child.id();

    {
        let mut rt = runtime.write().await;
        rt.status = ProcStatus::Running;
        rt.pid = pid;
        rt.started_at = Some(Instant::now());
    }

    if let Some(out) = stdout {
        spawn_reader(out, runtime.clone());
    }
    if let Some(err) = stderr {
        spawn_reader(err, runtime.clone());
    }
    Ok(child)
}

fn spawn_reader<R>(reader: R, runtime: Arc<RwLock<ProcRuntime>>)
where
    R: tokio::io::AsyncRead + Unpin + Send + 'static,
{
    tokio::spawn(async move {
        let mut lines = BufReader::new(reader).lines();
        while let Ok(Some(line)) = lines.next_line().await {
            runtime.write().await.logs.push(line);
        }
    });
}
```

### Task 8: 监督循环 supervisor

**Files:**
- Create: `src/core/supervisor.rs`
- Modify: `src/core/mod.rs`

**Interfaces:**
- Consumes: `state::{SharedState, ProcStatus}`、`process::spawn_process`、`backoff::Backoff`、`config::model::{ProcessDef, RestartPolicy}`
- Produces:
  - `Supervisor::new(state: SharedState) -> Supervisor`
  - `start(&self, name: &str) -> Result<()>`:找到 def+runtime,派生一个监督 task(spawn→wait→按策略重启),task 句柄存入内部表以便 stop。
  - `stop(&self, name: &str) -> Result<()>`:kill 子进程,标记 Stopped,取消监督 task 的重启。
  - `restart(&self, name: &str) -> Result<()>`:stop 后 start。
  - `start_autostart(&self)`:遍历 config,对 `autostart==true` 的进程调用 start。
  - `shutdown(&self)`:停止所有进程。
- 监督 task 内部逻辑:循环 { spawn_process → child.wait() → 据 exit status 与 RestartPolicy 决定是否重启;需重启则置 Restarting、按 backoff 延迟、restart_count++、超过 max_retries(非0)则置 Crashed 退出;正常停止则置 Stopped 退出 }。stop 通过一个 per-process `watch`/`Notify` 取消信号打断。

```rust
use crate::config::model::{ProcessDef, RestartPolicy};
use crate::core::backoff::Backoff;
use crate::core::process::spawn_process;
use crate::core::state::{ProcStatus, SharedState};
use crate::error::{PerchError, Result};
use std::collections::HashMap;
use std::sync::Arc;
use tokio::sync::{Mutex, Notify};

pub struct Supervisor {
    state: SharedState,
    stops: Mutex<HashMap<String, Arc<Notify>>>,
}

impl Supervisor {
    pub fn new(state: SharedState) -> Arc<Self> {
        Arc::new(Self { state, stops: Mutex::new(HashMap::new()) })
    }

    async fn find_def(&self, name: &str) -> Result<ProcessDef> {
        let cfg = self.state.config.read().await;
        cfg.process.iter().find(|p| p.name == name).cloned()
            .ok_or_else(|| PerchError::Process(format!("unknown process: {name}")))
    }

    pub async fn start(self: &Arc<Self>, name: &str) -> Result<()> {
        let def = self.find_def(name).await?;
        let runtime = {
            let procs = self.state.procs.read().await;
            procs.get(name).cloned()
                .ok_or_else(|| PerchError::Process(format!("no runtime: {name}")))?
        };
        {
            let mut stops = self.stops.lock().await;
            if stops.contains_key(name) {
                return Ok(()); // 已在运行
            }
            stops.insert(name.to_string(), Arc::new(Notify::new()));
        }
        let notify = self.stops.lock().await.get(name).unwrap().clone();
        let this = self.clone();
        let name_owned = name.to_string();
        tokio::spawn(async move {
            this.supervise_loop(def, runtime, notify, name_owned).await;
        });
        Ok(())
    }

    pub async fn stop(&self, name: &str) -> Result<()> {
        let notify = { self.stops.lock().await.remove(name) };
        if let Some(n) = notify {
            n.notify_waiters();
        }
        if let Some(rt) = self.state.procs.read().await.get(name).cloned() {
            let mut r = rt.write().await;
            r.status = ProcStatus::Stopped;
            r.pid = None;
        }
        Ok(())
    }

    pub async fn restart(self: &Arc<Self>, name: &str) -> Result<()> {
        self.stop(name).await?;
        tokio::time::sleep(std::time::Duration::from_millis(300)).await;
        self.start(name).await
    }

    pub async fn start_autostart(self: &Arc<Self>) {
        let names: Vec<String> = {
            let cfg = self.state.config.read().await;
            cfg.process.iter().filter(|p| p.autostart).map(|p| p.name.clone()).collect()
        };
        for n in names {
            let _ = self.start(&n).await;
        }
    }

    pub async fn shutdown(&self) {
        let names: Vec<String> = { self.stops.lock().await.keys().cloned().collect() };
        for n in names {
            let _ = self.stop(&n).await;
        }
    }
}
```

```rust
impl Supervisor {
    async fn supervise_loop(
        self: Arc<Self>,
        def: ProcessDef,
        runtime: std::sync::Arc<tokio::sync::RwLock<crate::core::state::ProcRuntime>>,
        notify: Arc<Notify>,
        name: String,
    ) {
        let mut backoff = Backoff::new(def.restart.backoff_secs, def.restart.backoff_max_secs);
        loop {
            let mut child = match spawn_process(&def, runtime.clone()).await {
                Ok(c) => c,
                Err(_) => {
                    runtime.write().await.status = ProcStatus::Crashed;
                    break;
                }
            };
            let stopped = tokio::select! {
                status = child.wait() => Some(status),
                _ = notify.notified() => {
                    let _ = child.kill().await;
                    None
                }
            };
            match stopped {
                None => {
                    // 收到 stop 信号,退出循环(stop() 已置 Stopped)
                    break;
                }
                Some(status) => {
                    let success = status.map(|s| s.success()).unwrap_or(false);
                    if !should_restart(def.restart.policy, success) {
                        runtime.write().await.status =
                            if success { ProcStatus::Stopped } else { ProcStatus::Crashed };
                        break;
                    }
                    {
                        let mut r = runtime.write().await;
                        r.status = ProcStatus::Restarting;
                        r.restart_count += 1;
                        r.pid = None;
                        if def.restart.max_retries != 0 && r.restart_count > def.restart.max_retries {
                            r.status = ProcStatus::Crashed;
                            break;
                        }
                    }
                    let delay = backoff.next_delay();
                    tokio::select! {
                        _ = tokio::time::sleep(delay) => {}
                        _ = notify.notified() => break,
                    }
                }
            }
        }
        self.stops.lock().await.remove(&name);
    }
}

fn should_restart(policy: RestartPolicy, success: bool) -> bool {
    match policy {
        RestartPolicy::Always => true,
        RestartPolicy::Never => false,
        RestartPolicy::OnFailure => !success,
    }
}
```

### Task 9: cron 定时任务调度 scheduler

**Files:**
- Create: `src/core/scheduler.rs`
- Modify: `src/core/mod.rs`

**Interfaces:**
- Consumes: `state::{SharedState, TaskRuntime}`、`config::model::TaskDef`、`process::build_command`
- Produces:
  - `Scheduler::new(state: SharedState) -> Arc<Scheduler>`
  - `start(self: &Arc<Self>)`:对每个 `enabled` 的 task 派生一个循环 task:据 cron 计算下次时间→sleep 到点→`run_once`。
  - `run_once(&self, name: &str) -> Result<()>`:据 TaskDef spawn 一次性子进程,`.wait()` 拿退出码,更新 `TaskRuntime.last_run`/`last_exit_code`,输出丢弃(MVP 不入进程 ring buffer,任务无常驻 runtime)。
  - `shutdown(&self)`:取消所有调度 task。

- [ ] **Step 1: 写 src/core/scheduler.rs**

```rust
use crate::config::model::TaskDef;
use crate::core::process::build_command;
use crate::core::state::SharedState;
use crate::error::{PerchError, Result};
use chrono::Utc;
use cron::Schedule;
use std::collections::HashMap;
use std::str::FromStr;
use std::sync::Arc;
use std::process::Stdio;
use tokio::sync::{Mutex, Notify};

pub struct Scheduler {
    state: SharedState,
    stops: Mutex<HashMap<String, Arc<Notify>>>,
}

impl Scheduler {
    pub fn new(state: SharedState) -> Arc<Self> {
        Arc::new(Self { state, stops: Mutex::new(HashMap::new()) })
    }

    async fn find_task(&self, name: &str) -> Result<TaskDef> {
        let cfg = self.state.config.read().await;
        cfg.task.iter().find(|t| t.name == name).cloned()
            .ok_or_else(|| PerchError::Process(format!("unknown task: {name}")))
    }

    pub async fn start(self: &Arc<Self>) {
        let tasks: Vec<TaskDef> = {
            let cfg = self.state.config.read().await;
            cfg.task.iter().filter(|t| t.enabled).cloned().collect()
        };
        for t in tasks {
            let notify = Arc::new(Notify::new());
            self.stops.lock().await.insert(t.name.clone(), notify.clone());
            let this = self.clone();
            tokio::spawn(async move { this.schedule_loop(t, notify).await; });
        }
    }

    async fn schedule_loop(self: Arc<Self>, task: TaskDef, notify: Arc<Notify>) {
        let schedule = match Schedule::from_str(&task.schedule) {
            Ok(s) => s,
            Err(_) => return,
        };
        loop {
            let next = match schedule.upcoming(Utc).next() {
                Some(n) => n,
                None => return,
            };
            let dur = (next - Utc::now()).to_std().unwrap_or(std::time::Duration::from_secs(1));
            tokio::select! {
                _ = tokio::time::sleep(dur) => { let _ = self.run_once(&task.name).await; }
                _ = notify.notified() => break,
            }
        }
    }

    pub async fn run_once(&self, name: &str) -> Result<()> {
        let task = self.find_task(name).await?;
        let mut cmd = build_command_for_task(&task);
        let mut child = cmd.spawn()
            .map_err(|e| PerchError::Process(format!("spawn task {name}: {e}")))?;
        let status = child.wait().await
            .map_err(|e| PerchError::Process(format!("wait task {name}: {e}")))?;
        if let Some(rt) = self.state.tasks.read().await.get(name).cloned() {
            let mut r = rt.write().await;
            r.last_run = Some(Utc::now());
            r.last_exit_code = status.code();
        }
        Ok(())
    }

    pub async fn shutdown(&self) {
        let all: Vec<Arc<Notify>> = { self.stops.lock().await.values().cloned().collect() };
        for n in all { n.notify_waiters(); }
        self.stops.lock().await.clear();
    }
}

fn build_command_for_task(task: &TaskDef) -> tokio::process::Command {
    let def = crate::config::model::ProcessDef {
        name: task.name.clone(), cmd: task.cmd.clone(), args: task.args.clone(),
        cwd: task.cwd.clone(), env: Default::default(), autostart: false,
        restart: Default::default(),
    };
    let mut cmd = build_command(&def);
    cmd.stdout(Stdio::null()).stderr(Stdio::null());
    cmd
}
```

- Produces:
  - `spawn_metrics_collector(state: SharedState)`:派生一个每 2 秒刷新的循环 task,用 `sysinfo::System` 按 pid 采集 CPU% 与内存字节,写回对应 `ProcRuntime`。pid 为 None 的进程置 0。

```rust
use crate::core::state::SharedState;
use std::time::Duration;
use sysinfo::{Pid, System};

pub fn spawn_metrics_collector(state: SharedState) {
    tokio::spawn(async move {
        let mut sys = System::new();
        loop {
            sys.refresh_processes();
            let entries: Vec<(String, Option<u32>)> = {
                let procs = state.procs.read().await;
                let mut v = Vec::new();
                for (name, rt) in procs.iter() {
                    v.push((name.clone(), rt.read().await.pid));
                }
                v
            };
            for (name, pid) in entries {
                let (cpu, mem) = match pid {
                    Some(p) => sys.process(Pid::from_u32(p))
                        .map(|proc_| (proc_.cpu_usage(), proc_.memory()))
                        .unwrap_or((0.0, 0)),
                    None => (0.0, 0),
                };
                if let Some(rt) = state.procs.read().await.get(&name).cloned() {
```

```rust
pub async fn require_token(
    State(ctx): State<WebContext>,
    req: Request<axum::body::Body>,
    next: Next,
) -> Result<Response, StatusCode> {
    let expected = ctx.state.config.read().await.server.token.clone();
    let provided = req
        .headers()
        .get(AUTHORIZATION)
        .and_then(|v| v.to_str().ok())
        .and_then(|s| s.strip_prefix("Bearer "))
        .map(|s| s.to_string());

        Some(t) if t == expected => Ok(next.run(req).await),
        _ => Err(StatusCode::UNAUTHORIZED),
    }
}
```

```rust
use crate::web::WebContext;
use axum::{
    extract::{Path, Query, State},
    response::sse::{Event, Sse},
    routing::get,
    Json, Router,
};
use futures::stream::Stream;
use serde::Deserialize;
use serde_json::json;
use std::convert::Infallible;
use std::time::Duration;

pub fn routes() -> Router<WebContext> {
    Router::new()
        .route("/processes/:name/logs", get(recent_logs))
        .route("/logs/stream/:name", get(stream_logs))
}

#[derive(Deserialize)]
struct LogQuery { lines: Option<usize> }

async fn recent_logs(
    State(ctx): State<WebContext>,
    Path(name): Path<String>,
    Query(q): Query<LogQuery>,
) -> Json<serde_json::Value> {
    let n = q.lines.unwrap_or(200);
    let lines = match ctx.state.procs.read().await.get(&name).cloned() {
        Some(rt) => rt.read().await.logs.recent(n),
        None => vec![],
    };
    Json(json!({ "name": name, "lines": lines }))
}

async fn stream_logs(
    State(ctx): State<WebContext>,
    Path(name): Path<String>,
) -> Sse<impl Stream<Item = Result<Event, Infallible>>> {
    let stream = async_stream::stream! {
        let mut interval = tokio::time::interval(Duration::from_secs(1));
        loop {
            interval.tick().await;
            let lines = match ctx.state.procs.read().await.get(&name).cloned() {
                Some(rt) => rt.read().await.logs.recent(50),
                None => vec![],
            };
            let payload = serde_json::json!({ "lines": lines }).to_string();
            yield Ok(Event::default().data(payload));
        }
    };
    Sse::new(stream)
}
```

```rust
}
```

```rust
use crate::config;
use crate::core::metrics::spawn_metrics_collector;
use crate::core::scheduler::Scheduler;
use crate::core::state::AppState;
use crate::core::supervisor::Supervisor;
use crate::web::{self, WebContext};

pub fn run() -> anyhow::Result<()> {
    let args: Vec<String> = std::env::args().skip(1).collect();
    match args.first().map(|s| s.as_str()) {
        Some("run") => {
            let rt = tokio::runtime::Runtime::new()?;
            rt.block_on(run_foreground())?;
        }
        Some(other) => {
            println!("子命令 '{other}' 将在阶段二实现(install/uninstall/start/stop)");
        }
        None => {
            println!("交互菜单将在阶段二实现;当前可用: perch run");
        }
    }
    Ok(())
}

async fn run_foreground() -> anyhow::Result<()> {
    let path = config::default_path();
    let cfg = config::load(&path)?;
    let bind = cfg.server.bind.clone();
    let state = AppState::new(cfg, path);

    let supervisor = Supervisor::new(state.clone());
    let scheduler = Scheduler::new(state.clone());
    spawn_metrics_collector(state.clone());
    supervisor.start_autostart().await;
    scheduler.start().await;

    let ctx = WebContext { state, supervisor: supervisor.clone(), scheduler: scheduler.clone() };

    println!("Perch 运行中: http://{bind}");
    tokio::select! {
        r = web::serve(ctx, &bind) => { r?; }
        _ = tokio::signal::ctrl_c() => { println!("收到 Ctrl-C,正在关停..."); }
    }
    supervisor.shutdown().await;
    scheduler.shutdown().await;
    Ok(())
}
```

```rust
use crate::error::{PerchError, Result};
use std::ffi::OsString;
use windows_service::service::{
    ServiceAccess, ServiceErrorControl, ServiceInfo, ServiceStartType, ServiceType,
};
use windows_service::service_manager::{ServiceManager, ServiceManagerAccess};

pub mod runner;

const SERVICE_NAME: &str = "Perch";

fn manager(access: ServiceManagerAccess) -> Result<ServiceManager> {
    ServiceManager::local_computer(None::<&str>, access)
        .map_err(|e| PerchError::Service(format!("open SCM: {e}")))
}

pub fn install() -> Result<()> {
    let mgr = manager(ServiceManagerAccess::CREATE_SERVICE)?;
    let exe = std::env::current_exe()
        .map_err(|e| PerchError::Service(format!("exe path: {e}")))?;
    let info = ServiceInfo {
        name: OsString::from(SERVICE_NAME),
        display_name: OsString::from("Perch Process Manager"),
        service_type: ServiceType::OWN_PROCESS,
        start_type: ServiceStartType::AutoStart,
        error_control: ServiceErrorControl::Normal,
        executable_path: exe,
        launch_arguments: vec![OsString::from("service")],
        dependencies: vec![],
        account_name: None,
        account_password: None,
    };
    mgr.create_service(&info, ServiceAccess::empty())
        .map_err(|e| PerchError::Service(format!("create: {e}")))?;
    Ok(())
}

pub fn uninstall() -> Result<()> {
    let mgr = manager(ServiceManagerAccess::CONNECT)?;
    let svc = mgr.open_service(SERVICE_NAME, ServiceAccess::DELETE)
        .map_err(|e| PerchError::Service(format!("open: {e}")))?;
    svc.delete().map_err(|e| PerchError::Service(format!("delete: {e}")))?;
    Ok(())
}

pub fn start() -> Result<()> {
    let mgr = manager(ServiceManagerAccess::CONNECT)?;
    let svc = mgr.open_service(SERVICE_NAME, ServiceAccess::START)
        .map_err(|e| PerchError::Service(format!("open: {e}")))?;
    svc.start::<OsString>(&[]).map_err(|e| PerchError::Service(format!("start: {e}")))?;
    Ok(())
}

pub fn stop() -> Result<()> {
    let mgr = manager(ServiceManagerAccess::CONNECT)?;
    let svc = mgr.open_service(SERVICE_NAME, ServiceAccess::STOP)
```

- [ ] **Step 4: 写 src/service/runner.rs(dispatcher + 优雅关停)**

```rust
use std::ffi::OsString;
use std::time::Duration;
use tokio::sync::oneshot;
use windows_service::service::{
    ServiceControl, ServiceControlAccept, ServiceExitCode, ServiceState, ServiceStatus, ServiceType,
};
use windows_service::service_control_handler::{self, ServiceControlHandlerResult};

const SERVICE_NAME: &str = "Perch";

windows_service::define_windows_service!(ffi_service_main, service_main);

pub fn run_as_service() -> Result<(), windows_service::Error> {
    windows_service::service_dispatcher::start(SERVICE_NAME, ffi_service_main)
}

fn service_main(_args: Vec<OsString>) {
    let (tx, rx) = oneshot::channel::<()>();
    let mut tx = Some(tx);

    let status_handle = service_control_handler::register(SERVICE_NAME, move |control| match control {
        ServiceControl::Stop => {
            if let Some(t) = tx.take() { let _ = t.send(()); }
            ServiceControlHandlerResult::NoError
        }
        ServiceControl::Interrogate => ServiceControlHandlerResult::NoError,
        _ => ServiceControlHandlerResult::NotImplemented,
    }).expect("register handler");

    let running = |state| ServiceStatus {
        service_type: ServiceType::OWN_PROCESS,
        current_state: state,
        controls_accepted: ServiceControlAccept::STOP,
        exit_code: ServiceExitCode::Win32(0),
        checkpoint: 0,
        wait_hint: Duration::default(),
        process_id: None,
    };
    status_handle.set_service_status(running(ServiceState::Running)).ok();

    let rt = tokio::runtime::Runtime::new().expect("runtime");
    rt.block_on(async {
        let _ = crate::cli::run_foreground_until(async { let _ = rx.await; }).await;
    });

    status_handle.set_service_status(running(ServiceState::Stopped)).ok();
}
```

```rust
#[cfg(windows)]
pub fn is_admin() -> bool {
    // 通过尝试打开 SCM 的 CREATE 权限或调用 Win32 API 判断;简化实现:
    use std::process::Command;
    Command::new("net").args(["session"]).output()
        .map(|o| o.status.success()).unwrap_or(false)
}

#[cfg(windows)]
pub fn relaunch_as_admin(arg: &str) -> crate::error::Result<()> {
    use std::os::windows::process::CommandExt;
    use std::process::Command;
    let exe = std::env::current_exe()
        .map_err(|e| crate::error::PerchError::Service(format!("exe: {e}")))?;
    // 用 PowerShell Start-Process -Verb RunAs 触发 UAC
    Command::new("powershell")
        .args(["-Command", &format!("Start-Process -FilePath '{}' -ArgumentList '{}' -Verb RunAs", exe.display(), arg)])
        .creation_flags(0x08000000) // CREATE_NO_WINDOW
        .spawn()
        .map_err(|e| crate::error::PerchError::Service(format!("relaunch: {e}")))?;
    Ok(())
}
```

注:`is_admin` 的 `net session` 是常见简易判断;若需严谨可改用 `windows` crate 的 `CheckTokenMembership`。MVP 用简易版,手动验证。

- [ ] **Step 2: 写 src/cli/menu.rs**

```rust
use crate::cli::elevate;
use std::io::{self, Write};

pub fn show() -> anyhow::Result<()> {
    loop {
        println!("\n=== Perch ===");
        println!("1) 安装服务  2) 卸载  3) 启动  4) 停止  5) 打开 Web UI  0) 退出");
        print!("选择: ");
        io::stdout().flush().ok();
        let mut line = String::new();
        io::stdin().read_line(&mut line)?;
        match line.trim() {
            "1" => privileged("install")?,
            "2" => privileged("uninstall")?,
            "3" => privileged("start")?,
            "4" => privileged("stop")?,
            "5" => { let _ = open_ui(); }
            "0" => break,
            _ => println!("无效选择"),
        }
    }
    Ok(())
}

fn privileged(action: &str) -> anyhow::Result<()> {
    if elevate::is_admin() {
        match action {
            "install" => crate::service::install()?,
            "uninstall" => crate::service::uninstall()?,
            "start" => crate::service::start()?,
            "stop" => crate::service::stop()?,
            _ => {}
        }
        println!("完成: {action}");
    } else {
        println!("需要管理员权限,正在请求提权...");
        elevate::relaunch_as_admin(action)?;
    }
    Ok(())
}

fn open_ui() -> std::io::Result<()> {
    std::process::Command::new("cmd")
        .args(["/c", "start", "http://127.0.0.1:9000"])
        .spawn()
        .map(|_| ())
}
```

- [ ] **Step 4: 写 manifest + build.rs 内嵌(触发 UAC)**

`perch.exe.manifest`:

```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<assembly xmlns="urn:schemas-microsoft-com:asm.v1" manifestVersion="1.0">
  <trustInfo xmlns="urn:schemas-microsoft-com:asm.v3">
    <security>
      <requestedPrivileges>
        <requestedExecutionLevel level="asInvoker" uiAccess="false"/>
      </requestedPrivileges>
    </security>
  </trustInfo>
</assembly>
```

注:用 `asInvoker` 而非 `requireAdministrator`——否则双击总是弹 UAC,且服务模式、`perch run` 都被迫提权。菜单里按需对特权操作单独提权(Step 1 的 relaunch)。

`Cargo.toml` 加 build 依赖并写 build.rs 用 `winres` 内嵌 manifest:

```toml
[target.'cfg(windows)'.build-dependencies]
winres = "0.1"
```

`build.rs`:

```rust
fn main() {
    #[cfg(windows)]
    {
        let mut res = winres::WindowsResource::new();
        res.set_manifest_file("perch.exe.manifest");
        let _ = res.compile();
    }
}
```
